# create-0xbasinas

A CLI tool to quickly scaffold Next.js 16 projects with shadcn/ui pre-configured.

## Installation

```bash
npx create-0xbasinas my-app
```

## Features

- 🚀 Next.js 16 setup
- 🎨 shadcn/ui components pre-configured
- 📦 TypeScript ready
- ⚡ Quick project scaffolding

## Usage

Create a new project:

```bash
npx create-0xbasinas my-project-name
cd my-project-name
npm install
npm run dev
```

## Requirements

- Node.js 18.17 or later
